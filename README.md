# MyNegosyo Website

A responsive MyNegosyo landing website with blue, red, and yellow branding.

## Install App

The site is PWA-enabled with `manifest.json` and `sw.js`.

In Google Chrome on desktop:
1. Open the site using HTTPS (or localhost during development).
2. Click **Install App** in the MyNegosyo header.
3. If the native prompt is available, click **Install MyNegosyo**.
4. Otherwise use Chrome's address-bar install icon or **⋮ -> Cast, save, and share -> Install page as app**.

## Deploy

Works as a static site on Vercel, Netlify, GitHub Pages, or any HTTPS static host.
